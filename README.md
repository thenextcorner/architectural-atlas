# Architectural Atlas

An interactive 3D atlas of famous architecture, built with React, Three.js, and shadcn/ui. Take **26 procedural buildings** apart into **4,779** individually selectable components, explore their **systems**, and search every named part.

Each building ships in two variants: **Simple** (around 30 schematic parts) and **Detailed** (100+ parts with full systems and explanations). The viewer defaults to Simple; switching to Detailed is one tap, and the choice is remembered per building.

Live at [architecturalatlas.com](https://architecturalatlas.com).

Forked from [Human Atlas by ashemag](https://github.com/ashemag/human-atlas) (MIT). The original anatomy dataset is replaced with procedural building models generated by `scripts/generate-*.mjs`.

## Explore

- The home page (`#/`) shows one card per building: title, location, blurb, and part count.
- Each building opens in the per-building viewer (`#/viewer/<slug>`), which is deep-linkable on static hosts because routing is hash based.
- Buildings with both variants show a Simple | Detailed toggle in the viewer header.
- Orbit, zoom, and select components directly on the structure.
- Toggle individual systems on and off.
- Move from the assembled structure to a spaced inventory of every visible piece.
- Search component names.
- Isolate a selected component and read its details.

All viewer content (systems, colors, descriptions, explanations, title, location, blurb, source links) is read from each building's `public/models/<slug>/atlas.json` at runtime. The code carries no building-specific data.

## Run locally

Requires Node.js 22.13 or newer. No API keys or accounts are needed.

```sh
npm ci
npm run dev
```

Open http://localhost:3016. To build the static site, run `npm run build`; the output is in `dist/`.

## Validate

```sh
npm run check
node scripts/generate-index.mjs
node scripts/validate-atlas.mjs <slug>/atlas.json
node scripts/validate-interactions.mjs
npm run build
node scripts/screenshots.mjs
```

`scripts/screenshots.mjs` captures `assembled.png` and `exploded.png` for every building into `../screenshots/<slug>/`. Pass one or more slugs to capture only those buildings, e.g. `node scripts/screenshots.mjs tower white-house`.

Validation covers the building index, mesh buffers, names and concept membership, nonoverlapping exploded layouts at desktop and mobile aspect ratios, search and inspection contracts, and tap-versus-drag handling for every building. Browser checks have exercised selection, system controls, search, isolation, rotation, and 390×844, 320×568, and 844×390 layouts. Phone controls stay clear of the exploded inventory, and isolated structures fit the space above or beside the detail panel. Physical-device performance and real multitouch hardware have not been tested.

## Building models

Each viewer shows a procedural, schematic model: named components in named systems, generated in code by `scripts/generate-<slug>.mjs` from verified reference dimensions. The packaged models contain tens of thousands of triangles and download a few hundred kilobytes of geometry each. They are schematic illustrations, not engineering models. Full credits and source links are in [ATTRIBUTION.md](public/ATTRIBUTION.md).

`public/models/index.json` (generated by `scripts/generate-index.mjs`) lists every building with its title, location, blurb, source links, system names and colors, and part counts. It is the single source of truth for the home page and the validation scripts; regenerate it after rebuilding any model.

## How it works

Geometry is merged into batches. Per-component GPU textures control translation, visibility, and selection, while component geometry supports accurate picking. Exploded layouts pack only the visible pieces. Rendering updates when the scene changes; orbit controls remain responsive without thousands of separate draw calls.

The optional WebMCP tools expose component search and inspection in compatible browsers. The visible interface works without them.

## Rebuilding geometry

The repository includes browser-ready geometry. Rebuilding it is optional: run `node scripts/generate-<slug>.mjs` to regenerate `public/models/<slug>/atlas.json` and `public/models/<slug>/<slug>-0.bin` from the procedural model definition, then `node scripts/generate-index.mjs` to refresh the building index.

## Deploy

The production site runs on Cloudflare Pages (`architecturalatlas.com`) via `wrangler pages deploy dist --project-name=architectural-atlas`. It can also be served by any static host: hash routing needs no rewrite rules.
